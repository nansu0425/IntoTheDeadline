# INTO THE DEADLINE

KRAFTON 정글 게임테크랩 2기 최종 게임잼에서 **Mundi 엔진**(교육과정에서 주차마다 서로 다른 팀이 이어 개발한 DirectX 11 엔진) 위에 만든 **FPS 좀비 서바이벌 게임**입니다.

마감에 쫓기는 직장인이 밀려드는 좀비 떼를 소총으로 상대합니다. 좀비는 기본형·추격형·자폭형·헐크형 4종에 보스가 있고, 피격 종류에 따라 화면에 화상·점액·감전 이펙트가 걸립니다.

## 핵심 작업

각 작업의 문제·설계·한계는 링크된 기술 문서에 정리했습니다. 문서는 `git blame` 으로 본인 작성 범위를 검증한 뒤 **그 범위만** 다룹니다.

### [피격 포스트프로세스 3종 — Fire · Slime · Electric](Docs/Feature_HitPostProcess.md) (게임잼)

몬스터 공격 종류별로 화면 전체에 거는 피격 이펙트 3종을 **Lua 게임플레이 이벤트 → 카메라 모디파이어 → 렌더패스 → 셰이더**까지 수직으로 구현했습니다. 셰이더는 텍스처 없이 노이즈·FBM 만으로 화염 혀, 흘러내리는 점액 방울과 굴절, 가지 치는 세그먼트 번개를 프로시저럴로 그립니다. 지속 시간 기반 페이드 아웃과 재시작 시 잔류 이펙트 제거까지 포함하며, 감전 이펙트는 플레이 테스트 피드백을 받아 눈 피로를 줄이는 방향으로 조정했습니다.

### [조명 시스템](Docs/Feature_Lighting.md) (WEEK07)

이 게임의 라이팅을 그대로 담당하는 조명 시스템입니다. Directional/Point/Spot/Ambient 4종 라이트, `USE_BLINN_PHONG` 등 include 전 매크로 정의로 조명 모델과 specular 색을 셰이더별로 바꾸는 공용 라이브러리, Unreal Engine 방식의 역제곱/지수 감쇠 2모드, 색온도의 C++ 사전 곱셈, OBJ/MTL 머티리얼 반영을 구현했습니다. 그림자 매핑과 타일 라이트 컬링은 팀원 작업입니다.

### [텍스처 DDS 베이킹·캐싱과 셰이더 핫 리로드](Docs/Feature_AssetPipeline.md) (WEEK07)

DirectXTex 로 PNG/JPG 원본을 BC1/BC3 압축 DDS 로 자동 변환·캐싱해 로딩과 VRAM 을 줄였습니다. 셰이더 핫 리로드는 `#include` 체인을 재귀 추적해 공용 셰이더 수정 시 의존하는 모든 셰이더의 매크로 variant 를 재컴파일하고, 컴파일 실패 시 직전 정상본으로 롤백합니다. 한글 경로 크래시는 UTF-8/UTF-16 경계 유틸로 해결했습니다.

### 그 외 (게임잼)

- **Red Dot Sight / ADS 전환** — iron sight 를 red dot sight 로 교체하고, 조준 시 팀원이 구현한 DoF 에 연동해 총기를 블러 처리, 크로스헤어 숨김
- **UberLit Alpha Test** — 텍스처 알파 기반 `discard` 로 풀·나무 식생 렌더링
